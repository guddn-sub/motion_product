21) 끊기지 않는 mp4

프롬프트

모션_작업실.html 맨 위의 약속을 따라 같은 폴더의 animation.js 를 만들거나 고쳐 줘. 브랜드 이름은 돌하르방, 한 글자는 돌, 슬로건은 돌하르방에 대하여 배워보아요. 이야.

render.mjs 를 만들어 줘. playwright-core 로 Chrome 을 띄워 모션_작업실.html?video&scene=all 을 열고, window.__ready 를 기다린 뒤 window.TOTAL_DURATION 동안 시간을 직접 옮기며 window.renderFrame(t) 으로 1초 60장을 찍어 mp4 로 만들어. canvas id 는 c 야. @ffmpeg-installer/ffmpeg 를 쓰고, JPEG 색을 BT.709 로 옮겨 표시까지 해. 필요한 설치도 해 주고 가장 짧은 장면으로 먼저 시험해 줘.

예상 결과

이렇게 나와요
mp4 파일이 생겨요. PC 가 느려도 끊기지 않아요.
아쉬운 점
소리는 없어요.
